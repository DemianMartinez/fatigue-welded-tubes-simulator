# Fatigue Simulator for Butt-Welded Tubular Joints

Final project for "Temas Selectos de Ingeniería Mecánica II" (Mechanical Engineering).

Simulates the fatigue process of two butt-welded steel tubes under cyclic load applied by a hydraulic cylinder, using the S-N curve (Basquin), Goodman mean-stress correction and Miner's cumulative damage rule.

## Project structure

- `src/` – simulator source code
- `data/` – input data and generated datasets
- `notebooks/` – exploration notebooks
- `app/` – Streamlit interface (optional)
- `tests/` – unit tests

## Requirements

See `requirements.txt`. Install with `pip install -r requirements.txt`.
